# CloudProbe 1.5.0 验证记录

日期：2026-10-25。验证范围为 Go WebDAV、界面读取流程、多文件调度和自动回退。

## 实网多文件

向专用目录提交 4 KiB、12 MiB、18 MiB、24 MiB 四份自造内容，分别使用 txt、zip、mkv、bin 文件名。后缀用于测试目录保留类型，并非解码或解压测试。

- 最高同时上传 3 个文件、下载 4 个文件，符合默认调度。
- 正文请求峰值 12，配置总预算 64；HTTP/2 可复用连接，此处不是 TCP 数量。
- 四文件上传约 43.127 秒，并行下载约 9.662 秒。
- 强制网易目录请求失败后，直连完整列出四个条目。
- 强制首选正文地址返回 503 后，实际使用联通直连 V2 完成下载。
- 四份完整 SHA-256 全部一致，客户端 Range 精确字节一致。
- 21 条回退事件，测试目录已清理。

原始结果见 multifile-verification.json。首轮测试识别到联通 systemDirs 的无 ID 系统入口元数据，修正解析并补充回归后重测通过；首轮测试目录也已清理。

## 实网普通 WebDAV 回归

新版调度与读取引擎通过中文特殊字符文件名、文本上传/下载、覆盖后回读、重命名和移动、复制、锁内保存与解锁、超过 10 MiB 上传、完整下载 SHA-256、HEAD、Range 和删除。仅操作本次生成的目录，已清理。见 real-webdav-verification.json。

## 自动化

最终 tests.txt、tests.jsonl 和 build-manifest.json 记录准确数量。测试包含实际 16 并发上传、8/16 并发下载、全局预算、FIFO 排队和取消、共享 Range 文件名额、元数据不等待正文、HTTP/1.1 与 HTTP/2 实际连接、自动切换协议且保留会话、正文断流按偏移恢复、401/403/429/5xx 回退、版本变化拒绝混合、错误 Range、无 Range 单路降级、目录多页和异常空响应、OpenList API/代理正文回退、写入不明不重放、凭据加密和跨域保护。

rclone 1.75.2 对隔离上游的互操作检查通过；go vet 通过。默认测试跳过真实账号用例。未运行 Go race detector，因为当前未配置可用的 C 编译器。
