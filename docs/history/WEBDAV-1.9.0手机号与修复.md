# CloudProbe 1.9.0：手机号登录与重要修复

日期：2026-10-29。

## 使用手机号登录

在“账号与登录 → 夸克网盘 → 登录方式”选择“手机号验证码（官网窗口）”，点击“打开手机号登录窗口”。若 WebDAV 正在运行，先停止服务再更新授权。

程序会使用本工具专用的新 Edge/Chrome 资料目录打开夸克官网，并切到“手机登录”。手机号、短信验证码及必要的官网验证由用户在官网输入或完成。工具不代发、不自动重发短信，不读取验证码输入框，也不读取个人浏览器资料。

完成后工具核验真实账号 UID，Windows DPAPI 加密保存会话，自动关闭本次专用窗口。同一账号更新凭据；不同账号单独添加。取消、超时、关窗和身份不一致会明确显示。取消已线性化在入库之前时，旧会话不能再提交。

本次真实手机号登录已通过，新增账号在当前运行实例中挂载为“夸克网盘-2”。原“联通云盘-1”和“夸克网盘-1”、密码校验值及全局传输参数均保留。

## 修复内容

| 编号 | 原问题 | 当前行为 |
|---|---|---|
| R1 | 夸克各候选沿用目录旧哈希，换源可能放行不同版本 | 目录哈希不再冒充不可变正文版本；中途续读依赖实际响应校验，无法核对时拒绝混合。联通不可变对象版本机制保留 |
| R2 | 取消/替换登录可能赶不上已验证会话的入库 | 提交与取消按顺序处理，核对登录代次；先成功保存加密资料再发布账号；保存失败不暴露待提交凭据 |
| R3 | 正常慢传也会触发固定三分钟分片超时 | 使用 90 秒无正文进度超时；持续进度可延长本次请求，客户端取消和连接/响应超时仍有效 |
| R4 | 通用下载器覆盖来源 User-Agent | 来源已提供时保留，只在缺失时设置默认值；跨域重定向凭据隔离不变 |
| R5 | OSS 完成只看状态码并吞掉响应体读取错误 | 有界完整读取，校验 XML/JSON 成功与错误；支持原生大写 Status 回调，不确定结果依内容哈希核对，不盲目重放 |

“无正文进度”指应用交给 HTTP 或读取响应的进度，不能等同于物理网卡瞬时吞吐。保留总体低速 X / 时间窗口 / Y 逻辑，可恢复故障继续无限重试。

## 上传方式与回退

夸克原生上传仍先计算完整 MD5/SHA1，明确使用磁盘兼容，并按上游要求顺序传片。联通仍可使用纯内存流水线。挂载表中的缓存选择可分别设置，互不强制改变。

桌面、网页、开放平台和已有 OpenList 候选按原有能力和授权参与回退。跨通道接续正文需版本可核对，业务拒绝、未知写入与部分执行不能当作可随意重放的网络故障。

## 构建与资料

独立二维码依赖和 vendor 补丁沿用 1.8.0；离线构建用 -mod=vendor，不要直接覆盖现有 vendor 本地补丁。

当前会话使用已有资料目录。压缩包不含登录资料；解压后默认启动脚本使用程序默认 AppData 资料位置。需要复用已有资料时，用 gui --data 指定对应本机目录。

参考接口与原驱动说明见“夸克驱动与通道说明.md”；参考项目许可与依赖许可随源码提供。
