# CloudProbe 1.10.0 · 云盘验证与 WebDAV

当前版本修复七项数据完整性与传输问题，增加夸克纯内存流水线及内存优先选择。夸克也可边接收边上传大文件，按原始正文计算完整散列，确认分片后释放缓存。详见《WEBDAV-1.10.0安全与内存.md》。本文后续保留早期功能说明，当前缓存行为和验证器规则以该文档为准。

本版加入联通纯内存流水上传、整个服务合计速度的低速恢复，以及可恢复上传/下载错误的无限重试。设置、缓存边界和验收见《内存上传与总体低速说明.md》。WebDAV 已用与剩余空间扩展继续保留，详见《容量配额说明.md》。

1.6.1 是维护修复：界面、默认值、登录和 WebDAV 使用方式与 1.6.0 相同。修正低预算等待、请求取消、账号隔离、提交核验、备用重放、失败锁和连接跟踪清理，详见《1.6.1修复说明.md》。

## 启动与登录

1. 解压整个目录，保留 sdk、bridge 文件夹，双击 cloudprobe.exe 或 启动界面.cmd。
2. 在“账号登录”页用网易爆米花手机 App 扫码，载入已绑定的云盘。原有本机测试登录可恢复。
3. 联通上传需要官网授权时，在“WebDAV 服务 → 联通官网备用登录”打开专用浏览器窗口，登录与绑定相同的账号，等待页面显示已保存。
4. 选择挂载、根目录和权限。联通根目录为 0，移动通常为 root。
5. 设置连接模式、文件并发、分片并发和大小。已有 WebDAV 密码留空会保留，首次留空自动生成。
6. 点击“启动 WebDAV”，将下方地址、用户名和密码填入第三方客户端，厂商选择 Other。

联通默认使用纯内存模式，需要客户端提供文件总长度；移动或需要整文件重读的备用上传应明确选择磁盘兼容模式。总体低速阈值默认 1 MB/s、窗口 5 秒、连续无效 3 次，所有上传文件相加判断并统一暂停 1 秒。设置在服务停止时可修改。

默认 WebDAV 地址是 http://127.0.0.1:50146/dav/，管理页使用另一个端口，二者不能混用。可选仅本机或局域网监听；管理页始终只监听本机。

正在运行时设置禁用，先停止服务再修改。保存新版本参数不需要重新登录云盘或生成新 WebDAV 密码。单纯关闭浏览器不会关闭后台；结束程序使用“诊断记录 → 关闭测试工具”。

## 默认传输参数

- 每文件联通上传并发 4、下载并发 8，均可配置 1—16。
- 同时上传 3 个文件、下载 4 个文件，均可配置 1—5，超过上限进入可取消队列。
- 上传分片 5 MiB，可配置 5—16 MiB。下载分片默认 5 MiB 自动模式，可配置 4—32 MiB 或固定模式。
- 正文 HTTP 请求总并发预算默认 64，最大 160；它统计正文请求/流，不是实际 TCP 连接数。目录等元数据操作不占正文名额。
- 上传自动模式在网络断流后重连并尝试另一种 HTTP 协议，保留会话与已确认分片。也可固定为 HTTP/1.1 独立连接或 HTTP/2 共享连接。

完整下载仅在 Range 和对象版本可核对时使用并行预取，按顺序交付正文。客户端自行发起 Range 时，本机不重复放大分片并发。无 Range 支持时完整下载退回单路读取；不把忽略 Range 的响应伪报成 206。

移动上传继续遵循官方开放接口的顺序分片约定，不能仅靠参数强行变成联通的独立分片协议。移动暂无本次真实账号验收。

## 自动回退

联通目录：网易代理 → 联通官网/绑定授权直连 → 已配置的 OpenList。联通下载正文：网易地址 → 直连 V2 → 直连 V1 → OpenList 直链 → OpenList 代理正文。

移动目录和下载可从网易代理回退官方开放接口，也可在完成映射核验后使用 OpenList 服务。每种方案仍需要适用的有效授权，不能凭空取得未授予的账号权限。

实际正文地址 401/403、5xx、连接错误和断流可触发候选切换，连续失败的方案会短暂冷却。按偏移恢复时检查大小、Content-Range、FID/ETag 等版本依据；无法确认时停止，避免混合不同内容。读取重试有次数和取消边界。

写入不是无条件重放。只有确定主操作未执行时才自动改用 OpenList。上传结果不明时先检查唯一临时文件，删除/移动/覆盖不明时明确报错，不为了自动回退而重复破坏性操作。

纯内存客户端上传不改用需要整文件重读的 OpenList 上传会话；其目录和下载备用能力仍保留。网络和服务临时错误的重试次数无上限，停止服务或客户端断开可取消。

## OpenList 备用服务

在 WebDAV 页下方为对应账号启用“OpenList 冗余服务”，填写已有服务地址、对应挂载目录、API Token 及必要的目录密码。支持 HTTPS 或本机 HTTP，例如 http://127.0.0.1:5244。

首次需要勾选允许创建并清理专用验证文件：主接口创建唯一小文件，经 OpenList 列表和正文核对同一目录，再清理。验证失败不启用，配置变更后重新核验。首次主接口需能够上传并清理该小文件。

令牌用 Windows DPAPI 加密保存在本机；留空保留先前令牌，取消启用后不参与回退。程序不自动安装 OpenList，也不会把网易或云盘登录凭据交给外部服务。OpenList 自身应已配置好相应云盘驱动。

本轮没有提供真实 OpenList 实例，协议适配已用隔离模拟服务验证，尚未完成真实外部服务验收。

## 文件与操作边界

支持 OPTIONS、PROPFIND、GET、HEAD、PUT、MKCOL、MOVE、COPY、DELETE、LOCK、UNLOCK 和条件保存。1.5.1 起支持 RFC 4331 已用与剩余空间属性，详见《容量配额说明》。保留目录、文本、压缩包、视频等实际文件条目，未知结构、不完整分页或异常省略列表不报告完整空目录。联通无文件 ID 的系统导航元数据单独记录。

上传先完整暂存到本机，需要对应空间，结束或失败后移除本地暂存。WebDAV 单文件上传默认上限 10240 MiB，可调整。WebDAV 下载不受旧文件验证页的 10 MiB 上限约束。

独立路径可并行操作；同一目标或祖先目录写入冲突返回 423。覆盖前保留旧文件，提交前发现外部修改返回 409，必要时保留 CloudProbe-upload-*、CloudProbe-backup-* 或 CloudProbe-partial-* 供检查。

不支持跨挂载 COPY/MOVE、自定义任意 WebDAV 属性或无限深度 PROPFIND。COPY 通过读取与重新上传实现。移动接口的写入仍受应用目录和后缀权限限制。

文件验证页也接入读取回退：先查询目录，服务器记住所选文件信息，再下载选择的文件。运行中的挂载可复用已配置 OpenList 映射；该页仍保留 10 MiB 的小文件验证上限，超过请使用 WebDAV。

## 日志、数据与构建

“诊断记录 → 本次运行记录”支持文件路径、请求编号搜索和来源筛选。记录文件队列、分片、接口回退、实际上传连接、节点读取与提交；HTTP/2 流与 TCP 连接分开说明。页面最近 800 条，完整本次日志写入数据目录 run-logs/*.jsonl，可导出。

运行日志不包含令牌、Cookie、签名 URL 或文件内容，但包含文件名和端点。登录资料、OpenList 凭据、暂存和原始运行日志均不在交付包中。

双击程序默认数据位于 %LOCALAPPDATA%\CloudProbeGUI；本聊天使用独立工作区资料。换到新数据目录启动可能需要重新扫码。WebDAV 密码只保存校验值；云盘和备用凭据使用 Windows DPAPI。

Windows 10/11 x64、.NET 8 x64 运行时，官网备用登录需 Edge 或 Chrome。运行已打包程序不需 Go。source 含全部 Go、页面、桥接和固定依赖源码；重新构建需要 Go 1.26+、PowerShell 7、.NET 8。先关闭程序，再执行 重新构建.ps1，默认测试不访问真实账号。
