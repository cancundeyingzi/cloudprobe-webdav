# 1.12.3 正文清理归属与旧云端事务收敛

本轮修复 1.12.2 隔离审查确认的两类生命周期缺口：请求成功或中止后，本地正文删除失败却没有归属；重建或放弃待提交任务时，旧云端对象和备份关系被清空。

## 独立正文归属

磁盘模式在接收任何正文前，先在 `webdav-spool/owners/` 登记正文文件名和目标，再创建正文文件。归属记录使用随机 ID、私有文件权限和系统文件锁，独立于上传检查点；每个资料目录最多 1024 条，达到上限时先处理待清理正文。此数量限制不代替磁盘正文总容量预算。

请求终结时先关闭正文句柄，再删除正文及归属记录。正文删除失败，归属记录保留；正文已删但记录删除失败，同样可重试。云端内容已确认成功时，局部清理失败不会把上传改报为失败，避免客户端为本地清理重复上传公网正文。

“本地正文清理”面板可以查看并重试。正在被其他请求或进程使用的正文受系统锁保护，不能从管理接口删除。进程强制退出后，新进程仍可根据记录清理，不要求原上传已经创建检查点。路径、记录 ID 和普通文件类型均受校验，不通过任意路径或目录前缀批量删除。

纯内存上传不创建正文归属记录或正文文件；它的磁盘内容仍只有会话、分片校验和事务元数据。

## 重建与放弃前的云端核验

内存任务因内容变化而重建，以及管理界面的 reset，共用旧事务收敛流程。处理前先将旧关系归档到 `resume/history/`，记录原账号身份、父目录 ID、目标名称、原对象、备份和已上传对象。原字段不会在归档成功前直接清空。

处理规则如下：

| 云端状态 | 行为 |
|---|---|
| 原目标不存在，匹配身份和版本的备份仍在 | 恢复原目标名称，并重新查询确认恢复成功。 |
| 最终目标已经是本任务核验过的上传对象 | 保留已提交的新内容，清理仍匹配原身份和版本的备份。 |
| 已上传临时对象仍存在，且身份、类型、版本均匹配 | 清理该受管理临时对象，并查询确认清理结果。 |
| 目标、备份或临时对象被外部修改，或结果无法确认 | 返回错误，保留活动检查点及历史记录，不覆盖或猜测删除。 |
| 只知道未完成会话，没有经过核验的对象 ID | 将会话和临时名称保留在历史中，不按名称猜测删除。 |

恢复或删除响应丢失时，通过重新查询判断结果；查询失败时保留恢复关系。自动重建只在旧事务已经收敛或关系已归档后创建新会话。恢复旧目标后，新一轮上传重新取得目标状态，不能沿用“目标不存在”的旧快照。

旧事务核验、恢复和清理只使用原生驱动。原生目录查询失败时，不使用 OpenList 只读备用的可见性或路径 ID 判断原对象已经不存在。

## 管理操作与兼容性

reset 需要核验已上传对象或备份时，要求原账号的 WebDAV 挂载处于运行状态，且目标路径仍映射到相同账号、父目录和名称。处理期间保留路径预约，并检查客户端 DAV 锁；启动/停止配置与管理核验串行交接。无法绑定资源或目标仍被锁定时，操作返回错误并保留记录。

新检查点持久化账号和父目录绑定。旧内存检查点可通过既有键重新验证绑定；旧磁盘检查点若没有这些字段，需要先由客户端以原文件重试一次以建立经过正文校验的绑定，不能仅凭挂载别名猜测。

“旧云端事务”面板显示归档状态及临时/备份名称，不返回会话授权和签名。历史记录使用原有本机保护机制：Windows DPAPI，其他平台私有文件权限。每条明文最多 5 MiB，最多 256 条历史；重复核验同一事务更新同一记录，不重复占用名额。达到上限时保留当前任务并提示处理历史。

确认关联对象已处理或无需继续跟踪后，可以明确移除该历史记录。该操作不执行云端删除，且与同一任务的恢复操作互斥。它不等价于将未核验的远端会话标为已清理。

## 验证

回归覆盖审查中的四个场景，并增加：正文在接收前已登记、活跃正文拒绝清理、强制终止真实子进程后通过管理接口回收、伪造路径保护、旧目标恢复失败与清理失败后的重试、外部目标/备份变化、错误账号、恢复/删除响应丢失、已提交目标保留、客户端文件锁及历史接口授权。

Windows 用真实文件共享删除限制验证清理失败；Linux 在非 root 进程中撤销暂存目录删除权限验证同类路径。云端使用模拟原生驱动检查对象 ID、内容版本和最终正文，没有执行真实网盘写入。历史上已经失去归属的旧残留不会通过这套新记录自动被识别。

2026-10-29 本机 Windows 验收结果：246 个顶层测试通过、0 失败；17 个真实环境测试和 3 个子进程入口按条件跳过，父测试实际执行子进程强制终止场景。新增 13 项适用于 Windows 的回归全部通过；Linux 权限拒绝用例、全量竞态检查随提交在 CI 执行。rclone 模拟互操作、go vet、界面脚本语法及 vendor 补丁检查通过。最终 CI 记录保存在交付包 verification.json。
