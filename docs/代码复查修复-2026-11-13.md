# 代码复查与修复记录（2026-11-13）

基线为 `d2863f4`，版本保持 `1.12.10`。本轮处理复查确认的五项问题，以及实施和复查中发现的关联缺陷。移动云盘专用协议、上传及移动/改名实现不在本轮范围内。

## 修复结果

### 条件读取的路径一致性

条件 GET/HEAD 从挂载根逐级核验路径，不再通过共享缓存寻找父目录。请求内固定挂载快照，只保留已验证的路径节点，使同一次请求的文件打开和元数据检查使用一致的映射。整份祖先目录列表由共享缓存管理，不随长时间下载一直保留。

回归覆盖祖先目录改名、同路径重建，以及 `If-Match`、`If-None-Match`、`If-Range`、`If-Modified-Since` 和 `If-Unmodified-Since`。普通 Range 读取仍能复用短期目录缓存；条件请求对每级祖先只查询一次。

实现主要位于 `dav_cache.go`、`dav_fs.go` 和 `dav_server.go`，回归位于 `dav_cache_test.go`。

### 并发下载的地址刷新与拒绝计数

下载地址每次解析产生一个代次。同一地址的一批并发失败只计一个刷新轮次；旧代次的失败、成功及正文中断不会使新地址失效或改变新的拒绝计数。地址解析排队支持取消。连续五个刷新轮次仍被 403 拒绝时停止该通道。

一次成功打开的正文请求同时持有响应、连接名额和地址代次，正文结束时一起释放。联通和夸克上传分片原有的逐次 403 上限保留。

回归覆盖 8/16 个并发分段、旧响应晚到、持续拒绝、刷新队列取消和连接预算释放。实现位于 `read_routes.go`、`transfer_reader.go`，回归位于 `download_retry_test.go` 和 `error_class_test.go`。

### 结构化错误与原始错误链

夸克授权错误先按业务分类处理；OpenList 的 HTTP 状态、业务状态和 `Retry-After` 单独保存，HTTP 200 不再遮蔽业务 429/503，非 JSON 错误页也保留 HTTP 失败状态。OpenList 的 HTTP 风格业务码仅在其专用错误类型中解释。

完整复查还发现了两处错误链丢失：`StageError` 只保存错误文案，桥接的“未执行”分支也会丢掉业务码。本轮补充原始原因和 `Unwrap`，使网络失败及业务授权错误能够穿过这些包装正确分类。未知写入结果的重放保护继续由写入层处理。

实现位于 `error_class.go`、`openlist_backup.go`、`model.go`、`bridge.go` 和 `quark_upload.go`。回归包括实际客户端网络失败、夸克分片授权恢复、OpenList 业务故障恢复及五轮拒绝终止。

### 管理请求与退出生命周期

查询和下载使用各自的请求上下文，账号和配置变更保留可取消的互斥控制。退出独立处理并且幂等：先取消界面请求，再触发应用关闭；排队中的控制操作也能退出等待。取消后的查询和下载不能发布成功结果。

浏览器验收中同时修复了退出后的界面状态：服务显示停止，等待中的操作显示取消，操作控件停用；迟到的状态和错误响应不能覆盖关闭提示。

实现主要位于 `gui_lifecycle.go`、`gui.go`、`gui_read.go` 和 `ui/app.js`，回归位于 `gui_lifecycle_test.go`。浏览器慢查询验收使用模拟账号和临时 overlay，不访问真实云盘。

### 目录缓存的容量和回收

共享目录缓存的 TTL 为三秒，同时限制最多 256 个目录、合计 50000 条目录项、估算快照大小 32 MiB。容量淘汰按插入顺序进行；访问、写入和失效操作会清理过期快照，包括之后没有再访问的旧目录。单个超限目录正常查询但不缓存。

容量计数、过期队列和删除操作统一维护。写入和挂载替换仍使相关快照失效，失效前启动的查询不能通过旧版本号重新填充缓存。请求内的路径节点与共享目录快照分开管理。
