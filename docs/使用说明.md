# 使用说明

## 启动

在 Windows x64 安装 .NET 8 Runtime，准备有权限使用的原版 SDK，然后从项目根目录启动：

```powershell
.\bridge\build.ps1 -SdkPath C:\path\to\authorized-sdk
go run -mod=vendor . gui --sdk C:\path\to\authorized-sdk --bridge .\bridge\build\CloudProbe.Bridge.dll
```

首次使用，在“账号与登录”完成所需云盘授权。每个云盘账号可以在 WebDAV 服务页单独挂载、选择根目录和读写权限。启动服务后，把页面显示的地址、WebDAV 用户名和已有密码填入第三方客户端。

## 夸克上传内存

在“WebDAV 服务 → 挂载与权限 → 上传缓存”选择模式：

- **内存优先**：原生桌面或网页通道先尝试纯内存流水；只有完整正文还未开始接收时，发现长度、通道或分片超过预算，才改用磁盘兼容。
- **严格纯内存**：正文不落盘，限制受单文件与全部上传内存预算约束；上游不可用时明确失败。
- **磁盘兼容**：接收并缓存完整正文后再上传，适用于开放平台、移动和需要整文件重读的备用通道。

上传内存与流水线页可设置默认缓存、单文件缓存上限、所有文件共用的总预算和预读量。夸克原生单文件按云端片号顺序发送；不同文件可以并发。客户端断开或程序重启后，当前版本不会从云端片号恢复整个上传任务。

## 访问范围

WebDAV 可监听本机或局域网。当前服务使用 HTTP Basic；跨不可信网络访问时，应通过可信隧道或 HTTPS 入口保护认证信息与传输内容。管理界面只监听本机。
