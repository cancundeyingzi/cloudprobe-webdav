# 使用说明

## 启动

在 Windows x64 安装 .NET 8 Runtime，准备有权限使用的原版 SDK，然后从项目根目录启动：

```powershell
.\bridge\build.ps1 -SdkPath C:\path\to\authorized-sdk
go run -mod=vendor . gui --sdk C:\path\to\authorized-sdk --bridge .\bridge\build\CloudProbe.Bridge.dll
```

首次使用，在“账号与登录”完成所需云盘授权。每个云盘账号可以在 WebDAV 服务页单独挂载、选择根目录和读写权限。启动服务后，把页面显示的地址、WebDAV 用户名和已有密码填入第三方客户端。

同一资料目录同时只运行一个实例。再次运行程序会重新打开现有管理界面。界面密钥仅随启动地址传给浏览器，网页本身不包含密钥；浏览器保存在本机存储中以便重开标签页。直接输入不含密钥的本机地址且浏览器没有有效会话时，请重新运行程序。

凭据更新触发的挂载验证若暂时失败，已经可用的挂载继续服务，并从 5 秒开始退避重试，最长间隔 5 分钟；界面会显示保留挂载及失败原因。首次挂载失败也会自动重试，仍可点击“重试加载”。

普通读取复用最多 3 秒的目录缓存；带 HTTP 条件头的读取刷新目标所在目录，经本服务执行写入后立即失效相关缓存。网络可恢复错误继续退避重试；同一传输通道刷新后仍连续 5 次被 HTTP 403 拒绝时结束请求，提示检查权限或重新登录，已有续传记录保留。

登录窗口关闭后会清理本次专用浏览器资料，失败时记录告警并在下次启动重试。启动时，界面查询的 `data/results/run-*` 目录保留最近 7 天、最多 50 次；过期查询记录与其中的测试下载文件会清理。命令行指定的结果目录和其他名称的目录不参与此清理。单实例保护与新旧版本的资料锁不兼容，升级前应退出旧进程。

云盘账号或目录可以读取、但无法写入时，仍允许启动 WebDAV 用于浏览和下载。页面会常驻显示受影响的挂载、路径、原因和处理办法：明确的写入拒绝提示上传会失败，未能验证写入能力则提示上传可能失败。实际上传、删除、改名等操作仍需云盘授权，不会因允许启动而绕过检查。恢复授权后可重启 WebDAV 重新检查；运行中某路径写入失败的告警会在同一路径、同类操作成功后清除。此行为不放宽本机 data 目录的权限要求。

首次启用 OpenList 的映射校验若被云盘明确拒绝写入，而内置目录读取正常，本次会继续使用内置读取通道并明确提示 OpenList 未启用。未经核验的备用映射不会用于读取或写入；配置仍保留，授权恢复后可重新核验。其他无法确认的校验失败仍会终止启动。

## 夸克上传内存

在“WebDAV 服务 → 挂载与权限 → 上传缓存”选择模式：

- **内存优先**：原生桌面或网页通道先尝试纯内存流水；只有完整正文还未开始接收时，发现长度、通道或分片超过预算，才改用磁盘兼容。
- **严格纯内存**：正文不落盘，限制受单文件与全部上传内存预算约束；上游不可用时明确失败。
- **磁盘兼容**：接收并缓存完整正文后再上传，适用于开放平台、移动和需要整文件重读的备用通道。

上传内存与流水线页可设置默认缓存、单文件缓存上限、所有文件共用的总预算和预读量。夸克原生单文件按云端片号顺序发送；不同文件可以并发。客户端断开或程序重启后，当前版本不会从云端片号恢复整个上传任务。

## 访问范围

WebDAV 可监听本机或局域网。当前服务使用 HTTP Basic；跨不可信网络访问时，应通过可信隧道或 HTTPS 入口保护认证信息与传输内容。管理界面只监听本机。
