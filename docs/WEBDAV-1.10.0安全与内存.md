# CloudProbe 1.10.0：安全修复与夸克内存上传

本版修复 1.9.0 审查确认的七项问题，增加夸克原生通道的有界内存流水上传。管理界面仍按账号、WebDAV、传输、浏览、日志归类。

## 上传缓存选择

在“WebDAV 服务 → 挂载与权限 → 上传缓存”可单独选择；“传输设置 → 上传内存与流水线”设置全局默认及内存上限。

| 方式 | 行为 |
|---|---|
| 严格纯内存 | 联通与夸克原生通道的完整 PUT 正文不落盘；不兼容时明确报错 |
| 内存优先 | 优先使用相同的内存流水线；仅在接收正文前确认长度、通道或分片预算不兼容时使用磁盘 |
| 磁盘兼容 | 完整接收并缓存正文后上传，支持需要预先完整散列或重读的通道 |

新夸克挂载推荐内存优先。已有挂载保存的选择继续生效；当前会话升级时按用户要求，将两个夸克挂载由磁盘兼容改为内存优先，其余挂载、密码及传输参数保留。

夸克原生桌面/网页通道先创建上传会话，按云端返回的片长顺序发送正文。客户端正文进入缓存时计算 MD5/SHA1；全部接收且分片确认后提交散列、合并并核验最终对象。失败片保留原始字节重试，确认后立即释放缓存。文件可以远大于内存窗口，客户端无需提供完整哈希。

实网已验证先传分片后提交散列的流程。夸克开放平台仍要求预上传散列，移动及需要完整重读的备用路径继续使用磁盘兼容。内存优先可以在准备阶段选择这些方式；开始发送正文、释放已确认分片后，不跨会话盲目重放。

默认每文件正文缓存上限 32 MiB、全部上传正文预算 128 MiB、提前接收目标 10 MiB，均可自定义。实际窗口同时受云端片长及并发影响，例如夸克返回 4 MiB 片长时，默认窗口约 14 MiB。夸克单文件仍顺序传片，多文件可以并发。

内存池使用可复用小块，整片预算一次申请，支持联通与夸克不同片长混用。预算不足时等待并向客户端施加背压，避免多文件各持有部分分片、却没有任何文件能取得完整分片空间。缓存上限约束正文缓存，不是整个进程、HTTP 缓冲及测试客户端的总内存。

严格纯内存需要可靠的 Content-Length；未知长度返回 411。内存优先遇到未知长度可在收包前选择磁盘。若云端单片超过配置的内存预算，严格模式明确报错，内存优先使用磁盘。内部 COPY 和 LOCK 创建空资源等路径可能使用磁盘暂存，纯内存承诺针对完整 PUT 正文。

## 七项修复

| 编号 | 修复 |
|---|---|
| R1 | 所有上传模式在接收正文前保留初始目标版本，收包后与提交前检查外部修改，发现冲突返回 409 |
| R2 | DELETE、MOVE、COPY、MKCOL 等变更统一执行 HTTP 条件；区分强/弱 ETag，支持 If-Unmodified-Since，条件判断使用新鲜目录 |
| R3 | 下载已选强 ETag 不降级到时间戳；恢复请求携带适用的 If-Range；时间戳作为强验证器还需满足响应日期要求 |
| R4 | ETag 纳入已知内容版本；具有完整哈希时不因修改时间单独波动改变内容验证器；缺少可靠内容版本的对象返回弱 ETag |
| R5 | PUT 成功响应使用提交后核验的对象，避免返回本地临时占位对象的 ETag |
| R6 | 夸克携带凭据的上传/下载地址要求 HTTPS，带凭据的 HTTPS 下载拒绝降级重定向 |
| R7 | 联通、移动与夸克采用无正文/响应进度超时，持续前进的慢传不再因固定三分钟被从片头重传 |

HTTP 条件用于目标资源；COPY/MOVE 的普通 If-Match 校验源，目标覆盖继续由 Destination、Overwrite 及 WebDAV 锁条件处理。云端接口不提供通用原子 CAS，因此外部应用在极短提交窗口内的竞争仍不能宣称完全消除；程序会在可观测的检查点核验，并保留不确定结果。

下载时，如果上游没有提供可信内容版本，服务会返回 W/ 开头的弱 ETag。普通 Range 仍可读取指定范围；弱 ETag 不能用于强 If-Range 或 If-Match。带弱 If-Range 时返回完整文件 200，避免把不同版本拼接为完整文件。客户端若需要恢复下载，应保存并使用可靠的强验证器；不能以单纯文件长度判定一致。

## 重试与续传边界

网络可恢复错误仍在当前请求内无限重试，保留退避、Retry-After、取消与服务停止。总体低速恢复继续按所有文件和线程的合计速度判断，并统一暂停一秒。

此次没有新增跨请求或跨重启的上传续传协议。客户端中断、程序退出或整个上游会话失效后，可能需要重新提交完整文件。内存缓存不是持久化检查点；已确认并释放的字节不能重新生成。

## 验证与使用

七项审查用例已从失败转为通过，补充了夸克流式哈希、重试超过旧上限、不同分片共享预算、准备阶段备用选择、弱验证器以及宽窄界面检查。最终测试数量、实网目录清理和内存峰值以随包 verification.json、quark-memory-live.json 等记录为准。

管理页与 WebDAV 使用不同端口。当前会话继续使用管理 http://127.0.0.1:50145/、WebDAV http://127.0.0.1:50146/dav/。运行时设置只读，修改前先停止 WebDAV，修改后重新启动。

程序仍只为本机管理页提供访问入口；WebDAV 可以选择局域网监听，但 HTTP Basic 本身不加密认证和正文。跨不可信网络应使用 HTTPS 入口或可信隧道。

交付包包含完整源码、vendor 本地补丁、原 SDK/桥接、许可证与脱敏验证记录，不含账号资料。默认启动脚本使用默认本机资料目录；复用现有资料时需给 gui 指定 --data。
