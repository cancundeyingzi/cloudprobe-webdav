# 架构复查与修复记录（2026-11-13）

本轮以 `e8b8a6f` 为基线，修复后续架构审查确认的七项问题。版本保持 `1.12.10`，移动云盘专用协议和写入实现继续排除。

## 状态与职责边界

- 读取会话持有内容版本；读取偏移、内容探测和预取生命周期独立处理。
- 读取通道持有地址代次、失败轮次和最早重试时间；解析与正文错误使用同一退避规则。
- 夸克凭据由统一更新入口协调，Cookie 与 OAuth 按渠道版本合并；账号实例区分删除前后的旧回调。持久化仅确认已经保存的版本。
- 挂载配置先合并，再通过同一校验器检查；恢复与自动新增也遵守相同约束。
- 夸克跨目录改名由独立操作流程管理暂存、移动、最终改名及可确认的恢复步骤。
- OpenList 的路径索引承担有界共享缓存职责；在途请求保留必要的已核验定位，不改变原生对象 ID。

没有新增外部依赖，凭据文件格式和配置格式兼容现有版本。Go 实现继续使用现有包结构，新增组件围绕状态所有权组织。

## 修复行为

### 多段读取与故障重试

回到偏移零不再清空内容版本。内容探测最多保存 512 字节用于回放，并继续原 HTTP 流；重新打开连接或切换来源仍须核验版本。逆序多 Range 不能把不同 ETag 的正文组合成成功响应。

地址解析与正文限流统一尊重 `Retry-After`，等待期间允许其他候选通道工作。同代失败只计一次刷新轮次，但可以合并更长的服务端延时；旧代响应不能改变新代状态。排队取得正文额度后会再次核对地址状态。

内部正文无进度超时与用户取消分开处理；前者可以恢复，后者立即退出且不处罚共享通道。通用失败轮次只在完整分段或正文成功后清零，连续截断仍执行递增退避。

### 夸克凭据

新登录首次加密保存成功后才发布；发布时替换对应授权渠道，同时保留其他渠道的并发更新。用旧会话发出的迟到响应不能覆盖新登录。

已在上游生效的轮换令牌或 Cookie 会先保留在内存，保存失败标记待保存并自动重试。请求取消可以离开保存队列，后台继续处理有效的新凭据。登录完成状态绑定自己的保存版本，重试成功后清除对应提示。

登录取消不等待磁盘写入；应用关闭冻结新回调并尝试有界最终保存。已经进入操作系统的文件写入不能强制取消，因此关闭等待超时时会返回保存失败，而不承诺新凭据已经落盘。

### 挂载配置与跨目录改名

完整配置校验包括缺席账号的保留挂载，拒绝重复名称、缺失身份、无效根目录和不兼容的同账号写权限组合。损坏配置继续保留原文件，使用已有重新读取或备份重置入口恢复。

夸克跨目录改名通过源、目标目录均未占用的临时名执行，每一步按对象 ID 和唯一名称核验。明确未执行的步骤可以在确认恢复目标未被占用后恢复；未知结果只做核验，不重放写操作。异常提示包含对象 ID 和最后核验位置。

### OpenList 路径索引

删除无用途的完整条目副本，共享路径索引最多 50000 条、估算 16 MiB，计入祖先定位、索引结构和映射容量。此上限只约束共享索引，目录缓存和在途请求分别管理其持有的状态。

完整列表替换旧快照，上传和建目录采用增量更新。目录发布顺序与位置版本阻止旧回包和已淘汰的旧节点重新生效；删除、移动及目录替换会使相关子树失效。请求中的目录读取与文件下载均保留必要定位，缓存淘汰后仍可继续正确回退。

## 完整复查中的关联修复

完整复查还覆盖了未直接改动的认证、写入提交、续传、正文归属、日志、桥接和发布流程，并处理以下关联问题：

- WebDAV 库同样将 POST 作为文件读取。POST 现与 GET 共用下载文件调度，并使用条件读取的新鲜元数据，避免绕过同时下载文件数限制。
- 桥接退出诊断仅读取锁内发布的退出状态，避免和 `exec.Cmd.Wait` 并发访问 `ProcessState`。
- 夸克登录收尾在管理器锁外脱敏，避免另一账号的本地保存阻塞取消或关闭。
- 续传恢复先补齐旧格式记录的资源身份，再重建对象的父目录和内容版本，保证严格改名核验兼容已有恢复记录。

复查采用独立的需求符合性检查和代码质量检查；确认的问题已修复并重新核对。模拟故障和交错回归整理为仓库内永久测试。
