# 发布审查修补说明

本轮修补针对 `22ae92a`（1.10.0）审查中列出的八项问题。验证使用本机模拟服务、管道和隔离凭据文件；不需要真实云盘账号。

## 写入与对象身份

OpenList 的 `openlist:路径` 仅表示位置，不能证明改名前后是同一个对象。因此，OpenList 备用保留目录、直链及代理下载能力，停止执行上传、覆盖、移动、删除和新建目录。原生写入失败，即便能确认尚未执行，也不会转交 OpenList。原生目录接口不可用时，HTTP 入口会在修改目标或创建备份前拒绝写入。

带 OpenList 备用的挂载仍可通过原生驱动执行写入，提交和清理继续要求稳定对象身份。路径 ID 不再通过 `sameCloudObject` 核验。

同账号同根目录的多个挂载，只要其中一个可写，就会被拒绝；两个只读别名仍可使用。账号身份会跨账号列表中的重复记录比较，联通、夸克的 `root` 和 `0` 会统一处理。这一限制没有覆盖无法从目录 ID 判定的祖先/子目录重复挂载，也没有覆盖其他进程或网盘客户端的写入。

## 凭据保存

只有凭据文件不存在时才初始化空存储。读取、解密、JSON 解析及结构错误均保留原文件并返回错误。更新使用副本构造，临时文件同步后再替换目标。

上游已轮换的新令牌保留在内存中，未保存的令牌单独记录；保存失败会显示常驻告警、事件和 `credential_save_pending`、`credential_save_error` 状态，每 30 秒重试。保存失败不会将已成功刷新的有效令牌标为不可用，刷新账号列表也会保留待保存的新令牌。重试仍执行完整读取和解析检查，不能自动覆盖损坏文件。保存成功后清除待保存状态，并保留其他账号及官网授权字段。待保存状态只存在于内存，进程异常退出前尚未保存的新令牌不能保证恢复。

Windows 使用 DPAPI；其他平台目前只有私有目录和文件权限保护。相应测试按平台检查实际能力，Linux 测试通过不代表已实现 Linux 凭据加密。

## Bridge 取消与关闭

Go 端采用容量为 32 的请求队列和专用协程，每次只向串行 SDK 发送一个命令。排队、发送、响应等待共享最长 40 秒的调用期限。发送前取消的命令不会进入 IPC；已发送命令取消后报告结果未知，并等待原命令结束后才发送下一条。已经进入 SDK 的写入仍需通过目录状态核验结果。

IPC 携带截止时间，.NET 端在调用 SDK 前拒绝过期请求。发送阻塞时取消会关闭管道并终止桥接。关闭服务直接关闭输入，最多等待两秒宽限期后终止子进程，不再排队发送 `stop`。主程序和 Bridge DLL 应一起更新。

## 资源边界

| 资源 | 行为 |
|---|---|
| 下载预取 | 独立全局预算默认 128 MiB；高级配置字段 `download_memory_mib` 接受 32—1024 MiB。整窗口申请，整窗口消费或丢弃后释放；预算不足时等待，取消可退出。预算约束预取正文，不是进程总内存。 |
| 下载调度 | `server` 模式下完整 GET 按请求占用文件名额；外部 Range 请求继续共享同文件名额。`client` 模式继续使用独立的正文连接和资源预算。 |
| 认证计算 | PBKDF2 并发不超过 4 且受 CPU 数约束；单来源突发 12、每秒补充 1，全局突发 16、每秒补充 8。来源取实际连接地址；过载返回 429。 |
| 认证缓存 | 仅缓存成功验证结果，最多 128 条、有效期一分钟，使用本次服务的随机 HMAC 密钥生成索引；用户名、盐或密码散列变更立即使旧索引失效。 |
| 入站请求 | 每个 WebDAV 服务最多接收 256 个活动请求，超出返回 503。 |
| 运行日志 | 每段最多 16 MiB；资料目录最多保留 8 个受管理日志段、预留总容量 128 MiB，保留期七天；启动与轮转时清理。导出包含本次运行仍保留的日志段。只清理本程序命名规则匹配的普通文件。 |
| 移动上传散列 | 每次最多读取 64 KiB 后检查取消；已取消请求不再完整扫描暂存文件。 |

日志达到上限且无法清理时会报告文件错误并停止磁盘写入，界面中的内存记录仍有独立数量限制。

## 构建与回归

`golang.org/x/net v0.61.0` 的三个 `publicsuffix/data` 文件已纳入源码交付范围。WebDAV 修改有可重放补丁与完整性检查，CI 从干净检出运行测试、静态检查和 Windows 构建，并在 Linux 执行竞态检测。

`release_safety_test.go` 的 14 个顶层测试覆盖 OpenList 完整 HTTP 写入拒绝及原生覆盖后的目标保留、凭据损坏与保存重试、SDK 刷新后新令牌继续可用、Bridge 管道阻塞与取消排队、重复可写挂载、下载预算及调度、认证缓存和限流、日志轮转和导出、移动上传取消。

驱动接口全面重构、内存与磁盘上传完成核验统一、进程崩溃后的持久化操作恢复日志、目录缓存总容量及磁盘暂存总预算属于后续工作。本轮没有实现这些架构扩展，也没有执行真实网盘故障注入。
