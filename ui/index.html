    上传
    云端上传与连接
    普通 PUT 不包含客户端线程设置，云盘分片由服务端管理。
    高级上传与资源保护
    联通每文件 1—16，默认 4。夸克按云端要求顺序传片，可同时传多个文件。
    连接模式以实际协议协商为准。正文请求预算和内存上限在两种调度方式下均生效，达到预算时排队或向客户端施加背压。
    
      
    下载
    下载请求与分片
    客户端 Range 请求按实际范围读取，避免叠加分片并发。
    普通 GET 使用单路读取；客户端发起多个 Range 时分别处理。需要服务端为单个 GET 并行加速，可切换为“服务端调度”。
    
      
    缓存与接收
    上传内存与流水线
    缓存接近上限时减慢客户端接收，让数据持续上传到云盘。
    缓存方式与适用范围
    严格纯内存适用于联通及夸克原生通道的完整 PUT，要求客户端提供总长度；正文不落盘，大文件也只保留有限窗口；少量会话及分片校验信息写入资料目录，用于重启续传。内存优先在接收正文前发现通道、分片预算或长度不兼容时可使用磁盘，日志会说明原因；正文开始后不盲目更换会话。夸克开放平台、移动和需要整文件重读的备用通道可用磁盘兼容。内部 COPY 可能落盘，缓存预算不等同于进程总内存。
    
      
    云端上传续传
    联通和夸克原生通道支持正文纯内存续传：磁盘只保存会话与分片校验，不保存正文。程序重启后由 CloudDrive2 完整重传局域网正文，逐片校验后复用云端进度。移动或不支持内存的通道使用磁盘兼容。
    点击刷新查看保留的云端上传进度。
    继续任务后，请让 CloudDrive2 重试上传。放弃续传会先核验待提交云端事务，必要时恢复原目标，再清理本地正文。无法确认时保留记录；未确认的旧云端会话保留在历史中。
    
      
    本地正文清理
    上传成功或取消后，无法删除的本地正文仍保留独立清理记录；重试清理不会重新上传公网正文。
    点击刷新查看正文清理记录。
    
      
    旧云端事务
    任务重建或放弃前保留旧对象关系。未确认的会话与临时对象可据此核验，确认已处理后再移除历史记录。
    点击刷新查看旧云端事务。
    
      
    低速恢复
    总体上传低速恢复
    统计所有文件、所有线程的上传正文速度合计。
    总体速度持续低于 X 时，所有上传统一暂停 1 秒后继续。连续 Y 次无改善，本次服务运行停止主动暂停；可恢复的网络错误仍无限重试。1 MB = 1,000,000 字节。
